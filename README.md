# ToyPLCollector

> A community gallery of toy programming languages — one TOML file per language,
> collected via PRs, published to the site automatically.

# Site

**[https://coll.i2pl.com/](https://coll.i2pl.com/)**

(Also reachable at <https://azhzx.github.io/ToyPLCollector/>. New languages appear on the site automatically.)

# How it works

```
A developer opens a PR (only adding collections/<language>.toml)
      └─► CI "Validate collections" checks the TOML / URLs / platform enum
      └─► a maintainer approves once
      └─► GitHub auto-merges (auto-merge, squash)
      └─► the site rebuilds and publishes automatically (index.html + one
          playground page per language)
```

Languages that ship a `playground` (wasm) can be edited and run right in the
browser — see the convention in
[CONTRIBUTING.md](CONTRIBUTING.md#2-online-playground--the-toypl-wasm-abi).

`assets/wasm/` holds maintainer-provided playground runtimes (e.g.
`riddle.wasm`); the build serves them from the site itself, so they load
same-origin without any CORS setup.

# Contribute

See **[CONTRIBUTING.md](CONTRIBUTING.md)** — copy
[`collections/riddle.toml`](collections/riddle.toml), fill it in, open a PR.

# Repo setup checklist (maintainer, one-time)

1. **Settings → Pages** → Build and deployment → Source: **GitHub Actions**
2. **Settings → General → Pull Requests** → ☑ **Allow auto-merge**
3. **Settings → Rules → Rulesets** → rules for the `main` branch:
   - Require a pull request before merging (1 approval)
   - Require status checks: `Validate collections`
   - Block force pushes / deletions
4. Custom domain `coll.i2pl.com`:
   - Bind it in the Pages settings (the build artifact contains a CNAME file
     generated by `make_website.py`)
   - Add a DNS record: `coll CNAME → azhzx.github.io` (point it at this
     account's github.io host, not any other)

# Local development

```bash
python3 main.py validate        # lint collections/*.toml
python3 main.py build           # generate the static site into _site/
python3 -m http.server -d _site 8000   # preview at http://localhost:8000
```
